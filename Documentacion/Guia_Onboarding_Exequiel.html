2. Configuración Automática

Copia el siguiente texto y pégalo directamente en tu chat con Antigravity. Él se encargará de clonar el repo, verificar tus instalaciones (SDK, Node, SQL) e instalar la herramienta de ABP CLI.

"Hola Antigravity, soy Exequiel y me estoy incorporando al proyecto TourismTracking. Por favor, ayúdame a configurar mi entorno de desarrollo desde cero. Realiza las siguientes tareas: 1. Recuperar Proyecto: Clona el repositorio https://github.com/ThiagoJGK/DesarrolloSoftwareGomezKehler.git. 2. Verificar Dependencias: Revisa si tengo instalados .NET 8 SDK, Node.js y SQL Server. 3. Instalar ABP CLI: Ejecuta 'dotnet tool install -g Volo.Abp.Cli' para habilitar las herramientas de ABP. 4. Base de Datos: Ejecuta el proyecto TourismTracking.DbMigrator para crear la DB local. 5. Frontend: Instala las dependencias de npm en la carpeta 'angular'."
